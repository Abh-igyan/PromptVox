# PromptVox: Antigravity Voice Typing 🎙️⚡

**Developed by Abhigyan Tiwari**  
*GitHub: [https://github.com/Abh-igyan/PromptVox](https://github.com/Abh-igyan/PromptVox)*

---

### Features
- **In-Panel Mic:** Adds a native microphone button directly to the Antigravity Chat panel header in VS Code.
- **Sub-Second Latency:** Powered by Groq Whisper Large-v3 (~200ms latency) via the local PromptVox daemon.
- **Bilingual Code-Switching:** Transcribes natural Hinglish speech into clean Latin/English text without unwanted Devanagari script or translated hallucinations.
- **Developer Token Formatting:** Preserves `C++`, `FastAPI`, `DSA`, `LeetCode`, and developer casing.
- **Global Hotkey:** Toggle anytime using `Alt + V` or `Ctrl + Alt + V`.

---

### Shortcuts
- **Start / Stop Dictation:** `Alt + V` or click the `$(mic)` icon in the Antigravity header / status bar.
- **Cancel Recording:** `Escape`
